# Fender Bandit

**Stop. Go. Oops.** A raccoon has gotten its paws on the city's traffic lights. Flip lights, keep the cars moving,
tow away the wreckage, and hold off gridlock for as long as you can.

**Play it on itch.io: https://kittypounce.itch.io/fender-bandit** (in the browser, or download for Windows). Submitted to the jam.

![A crash at stage 9](docs/art/itch/1-crash.png)

A solo entry for the [2026 HCSS Game Jam](https://itch.io/jam/2026-hcss-game-jam), on the themes *Raccoons* and
*Accidents happen!* Built in Godot 4.7 with GDScript. All art, audio and code were produced with AI tools, directed
by the developer.

## Controls

Keyboard or gamepad (arcade-cabinet friendly), no mouse.

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / arrow keys | D-pad |
| Toggle a traffic light | J | A |
| Dash | Space | X |
| Tow wreckage | L | Y |
| Pause | Esc, P or Enter | Start |

## How Fender Bandit was built

The developer directed everything; [Claude Code](https://claude.com/claude-code) (Claude, working in the terminal)
wrote it. No asset was drawn, recorded or coded by hand.

- **Process.** Each feature started as a GitHub issue. Claude and the developer grilled the design one question at a
  time, then Claude built it test-first and closed the issue with notes. Throwaway prototypes settled the core feel
  before the real game was built. Playtest feedback went back into issues and tuning tables ([docs/tuning.md](docs/tuning.md)).
- **Gameplay.** It's Godot 4.7 and GDScript, all written by Claude. The traffic simulation is plain code stepped at a
  fixed 60 Hz, so a seeded run repeats exactly (see the [ADR](docs/adr/0001-plain-code-traffic-sim.md)). That makes
  it testable: about 250 headless tests, a smoke test that plays the whole arcade loop, and an autopilot that plays
  the game in Attract mode. Claude checked its own visual work by taking screenshots of seeded runs and reading them.
- **Graphics.** Every sprite is a flat vector SVG that Claude wrote as text, following a style sheet and sprite list
  in [docs/sprites.md](docs/sprites.md) that keep the art consistent. The Raccoon is a cutout rig of SVG parts animated
  in code. Menus are road signs drawn in code, set in the [Bungee](https://fonts.google.com/specimen/Bungee) font (OFL).
- **Audio.** Every sound effect is generated by a seeded GDScript synthesizer (`game/tools/make_sfx.gd`), in the
  manner of jsfxr, so it rebuilds byte for byte. The music is composed the same way
  (`game/tools/make_music.gd`): seeded jazz-funk loops in D minor. Recipes and loop points are in
  [docs/audio.md](docs/audio.md).

## Development

The Godot project is in `game/`; open `game/project.godot` in Godot 4.7.2. From the repo root in Git Bash:

| Task | Command |
|---|---|
| Run the tests | `game/tools/test.sh` |
| Run the headless smoke test | `game/tools/smoke.sh` |
| Export the Web and Windows builds | `game/tools/export.sh` |
| Serve the web build at http://localhost:8060 | `node game/tools/serve_web.mjs` |
| Publish to itch.io | `game/tools/publish.sh` (see [docs/publishing.md](docs/publishing.md)) |

- [CONTEXT.md](CONTEXT.md): the domain language (Raccoon, Light, Switch, Jam, Gridlock, ...)
- [docs/adr/](docs/adr/): architecture decisions
- [docs/tuning.md](docs/tuning.md): every gameplay tuning knob
- [CLAUDE.md](CLAUDE.md): the full command list and working notes
